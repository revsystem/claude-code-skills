## 捨てた選択肢と理由
- 「起動したエージェントが自律的にモデルとエフォートを選ぶ」原文どおりの仕様: 起動後に自分のモデルを切り替える手段が herdr にも各 CLI にも無い — 司令塔が起動引数で渡す形に書き直した
- 起動後に `/model` をプロンプト本文で送ってモデルを変える案: スラッシュコマンドの体系が kind ごとに違い、ピッカー UI を開くだけの入力は `agent_prompt_stalled`（投入後 5 秒でライフサイクル変化が無い）になり得る。起動引数が使えるのに事後変更に頼る理由が無い — 採用せず
- ペイン上限を固定 3（司令塔 + 2）にする cursor レビュアー案: herdr スキルが既にレイアウト依存の判断を求めているので、固定数より導出が整合する — claude レビュアー案（司令塔 + 3、レイアウト導出）を採用
- 並列投入を `--wait` 無しの素の `prompt` で行う cursor レビュアー案: 5 秒の stall 検出（`agent_prompt_stalled`）を失う — `--wait --until working --until blocked` 形を採用
- 役割名（司令塔、実装担当など）をそのまま agent 名に使う案: 名前の制約は `[a-z][a-z0-9_-]{0,31}` かつ live agent 全体で一意。日本語は通らず、`reviewer` のような一般名は別ワークスペースと衝突する — `impl-1` / `review-auth` のように役割と対象を組む形にした
- 既存ペインのモデルを変える案: 起動し直しになりセッションが消える — 既存ペインのモデルは変えない、と明記した
- worktree で実装担当を分離する案: herdr スキルがユーザーの明示要求を求めているので既定にできない — 分担表で担当ファイルを排他にする方針にした
- Agent ツールのサブエージェントで検討する解釈: 同一 workspace に idle な sibling ペインが 2 つあり、題材が herdr 分担スキルそのものだったため、ペインへの委譲と読んだ
- 検討段階で SKILL.md を編集する進め方: ユーザーの依頼は「成り立つかを検討してほしい」だった — 研究メモを先に書き、実装可否をユーザーに確認してから着手した

## 学び
- `herdr agent start` はシェルプロンプトにいる空ペインを要求する（`agent start --help` の "Existing pane at an interactive shell prompt"）。agent が動いているペインには起動できないので、「各ペインでエージェントを起動する」という仕様は既存ペインには適用できない
- `herdr agent prompt --wait --until working --until blocked --timeout 10000` は受理されて動き出した時点で返る。`done` 状態のペインへ送って 419ms で `working` が返ることを実測した。これで stall 検出を残したまま複数ペインへ順次投入できる
- `--wait` 無しの素の `prompt` でも並列投入自体は成立する（2 ペインへ連続投入して両方 `working` に入ることを実測）。ただし stall 検出が無い
- `herdr agent list` はサーバ全体（今回は 5 workspace 15 agent）を返す。agent 名の一意性が live agent 全体で要求されるため、`reviewer` のような一般名は現実的な確率で衝突する
- `herdr agent list` / `agent get` の JSON に `name` キーは無かった（名前付き agent が無いのか list が出さないのかは未確認）
- モデル指定手段は kind ごとに違う。claude は `--model` と `--effort`（low/medium/high/xhigh/max）、cursor-agent は `--model` のみでエフォートはモデル名の角括弧オーバーライド、codex は `-m` と `-c key=value`（エフォート相当のキー名は未確認）、gemini と copilot は `--model` のみ
- この環境にインストール済みの kind は claude, codex, gemini, cursor, copilot, kiro の 6 つ。herdr が受け付ける kind は 23 種類あるが、ユーザーに尋ねるときは `command -v` で絞る
- `herdr pane layout` の実測で、wE:t1 は 265x71、右列が 132x36 と 132x35。6 ペインは 3 列 2 行で約 88x35 となり物理的には入るが余裕が無い
