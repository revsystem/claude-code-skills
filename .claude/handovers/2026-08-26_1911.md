## 学び
- `herdr agent list` の `focused` は「ユーザーが今見ているペイン」を指す。自分の特定には `herdr pane current` を使う
- herdr 0.8.2 では `herdr agent prompt <target> --wait` の既定が idle/done/blocked のため `--until` を重ねない。`--until` は特殊な待ち方専用。`agent prompt` は相手が blocked だと `agent_blocked` で拒否、投入後 5秒以内に状態変化が無いと `agent_prompt_stalled`
- pane/tab/workspace の公開 id は安定ハンドルで、閉じても再利用されない（旧スキルの「詰め直される」は誤り）。自分の位置は `$HERDR_WORKSPACE_ID` / `$HERDR_PANE_ID` で取れる
- 長い回答が読めないのは相手が代替画面で動いている場合。ファイル出力の依頼は最初からではなく、読めなかったときの回避策として使う
- `agent prompt --wait` はターンを追跡しないため、相手が既に working だとその turn の完了を掴む。送信前に idle / done を確認する必要がある
- 過去セッションの指示文は transcript（`~/.claude/projects/<slug>/*.jsonl`）から取り出せる。type == "user" の message.content を拾えば、ユーザーの原文をそのままスキルの方針に落とせる
- `gh skill install` / `update` は git tag ではなく GitHub Release の Latest を解決する。タグを push しただけでは新スキルが配布されない
